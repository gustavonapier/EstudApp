# EstudApp

Este é um projeto de aprendizado que consiste em uma tela inicial de um aplicativo de estudos. A tela foi desenvolvida com HTML e CSS para proporcionar uma interface intuitiva. Além disso, essa página está linkada a uma tela de cadastro que fiz, mais reutilizei para simular o cadastro do App.
